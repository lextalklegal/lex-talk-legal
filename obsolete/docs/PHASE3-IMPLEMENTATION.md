# Lex Talk Legal — Phase 3 Implementation

## Scope

This release improves the production site's content plumbing, analytics coverage, timestamp consistency and monetisation-oriented discovery without changing the locked common Header, Navigation/Menu or Footer design.

## Implemented

1. **Site-wide GA4**
   - Measurement ID: `G-3KT3SQPFXD`
   - Added centrally to `scripts/build_site.py` page shell.
   - Existing public/static HTML pages were normalised to contain one loader and one config call.
   - `scripts/smoke_test.py` now fails if a public page loses the GA tag or receives a duplicate.

2. **GA interaction events**
   - `sponsor_click`
   - `youtube_click`
   - `contact_click`
   - `whatsapp_click`
   - `external_link_click`
   - Pass The Bar links carry campaign metadata.

3. **Unified publication timestamp**
   - `data/site_meta.json` is the single current timestamp source.
   - `assets/site.js` hydrates `.updated-line` with the exact IST date/time.
   - Editorial, VC, Jobs and Auctions builders now refresh `site_meta.json`.
   - Those workflows commit `data/site_meta.json` with their output.
   - Footer HTML/design remains unchanged.

4. **Explained / evergreen hub**
   - Added `templates/category/explained.html`.
   - Added `assets/pages/explained.css`.
   - The common builder owns the Explained landing page and fills its reusable guide library.
   - The hub connects readers to Courts, Law & Policy, Banking & Recovery, DRT / DRAT, Legal Careers and DRA resources.

5. **Legal Careers discovery**
   - Added a Career Resources section linking to the Legal Jobs Board, AIBE preparation and India Code.
   - Existing sponsored AIBE placement remains clearly labelled and isolated from editorial endorsement.

6. **SEO sitemap coverage**
   - Added `/jobs/` and `/advertise.html` to the standard sitemap.
   - News sitemap remains reserved for recent news articles.

7. **Regression protection**
   - Page-design ownership remains explicit.
   - Approved pages have CSS/design contracts in `scripts/smoke_test.py`.
   - Protected pages are not regenerated by the common editorial builder.

## Files intentionally not redesigned

- Common Header
- Navigation / Menu
- Common Footer
- Existing approved page-specific CSS for About, Courts, Law & Policy, Banking Law, DRA, Videos, Contact, Case Status and Courtrooms
- PIB Radar discovery workflow
- OneCourt automatic scraping is not reintroduced

## Deployment

1. Replace same-path files in GitHub; do not delete unrelated repository files.
2. Commit and push.
3. Let `Deploy Lex Talk Legal Worker` complete GREEN.
4. Run `Lex Talk Legal - Editorial Sync` once manually.
5. Confirm both workflows are GREEN.
6. In GA4, open **Reports → Realtime** and visit the site in a separate browser tab.
